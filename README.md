# NEWWEBSITE

## View the site locally

From the repository root, start a local server (make sure you are in the folder that contains `index.html`):

```bash
cd /path/to/NEWWEBSITE
python -m http.server 8000
```

Then open the page in your browser:

```
http://127.0.0.1:8000/index.html
```

If a server is blocked in your environment, you can also open the file directly:

```
file:///path/to/NEWWEBSITE/index.html
```

### Windows example

```bat
cd C:\path\to\NEWWEBSITE
python -m http.server 8000
```
